# The speech engine lives in requirements-engine.txt, not here.
#
# Split because the two have very different costs: this file installs in
# seconds and runs in a few hundred megabytes, while the engine pulls PyTorch
# and needs gigabytes of RAM to hold its models. A deployment that cannot
# afford the second can still run everything else.
#
# Installing only this file is a supported configuration, not a broken one.
# The engine's imports are inside its providers, so the app starts, and each
# affected dimension reports itself unscored with a reason rather than being
# guessed at. `GET /healthz` says which tier is live.
#
#   pip install -r requirements.txt                      # Tier 0 only
#   pip install -r requirements.txt -r requirements-engine.txt   # full
